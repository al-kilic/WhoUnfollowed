# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, please do not open a public issue.

Email: **aekilicc@gmail.com**  
Subject: `[SECURITY] WhoUnfollowed - brief description`

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

**Response SLA:** I will acknowledge within 48 hours and aim to patch within 7 days for critical issues.

## Scope

- Client-side data leakage (ZIP contents sent off-device without consent)
- Auth bypass or privilege escalation (Pro tier)
- XSS or injection vulnerabilities in the web app

## Out of Scope

- Theoretical attacks with no practical exploit
- Issues in third-party dependencies (report to those projects directly)
